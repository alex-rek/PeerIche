# Встроенный каталог серверов

В APK включён объединённый список из 1956 уникальных доменов официального каталога PeerTube и FediDB. Ресурс `assets/peertube-servers.txt` занимает 16874 байта после сжатия в проверочной сборке. Сведения об источниках и лицензии FediDB CC BY 4.0 находятся в `assets/licenses/Server-catalog.txt` и доступны по ссылке в настройках.

В «Настройки → Серверы» список доступен сразу. «Обновить список серверов» загружает все страницы официального каталога и актуальную выгрузку доменов FediDB. Результат сохраняется в DataStore отдельно от APK. При полном обновлении список заменяется, при доступности одного источника его адреса объединяются с сохранёнными. При сбое обоих источников остаётся прежний список. Автоматических обновлений каталога при запуске нет.

При отсутствии выбранного вручную сервера и действующего аккаунта приложение использует автовыбор. Случайная группа до 32 адресов проверяется восемью запросами одновременно с ограничением времени каждого запроса в четыре секунды. Выбирается минимальное время полного ответа API среди серверов, вернувших корректную ленту с видео. Это время ответа HTTPS API, не ICMP ping и не глобальный минимум по всему каталогу. Повторная попытка проверяет новую группу. Сервер аккаунта применяется, если ручного выбора нет. Сохранённый ручной выбор имеет приоритет.

В меню сервера есть пункт «Автовыбор» для просмотра без действующего аккаунта. Начальная загрузка ленты ожидает результата выбора. Сам каталог не добавляется целиком в список подключённых источников поиска. Проверка доступности в настройках обрабатывает первые 50 серверов текущей сортировки/фильтра и показывает их количество на кнопке.

Проверки прошли на debug и androidTest сборках. Выполнены 166 модульных тестов, Lint без ошибок. Тесты покрывают объединение и частичное обновление, приоритет ручного выбора и аккаунта, выбор минимального времени, ограничение параллелизма и отмену запросов. На Android проверены чтение встроенного ресурса, обновление обоих источников, сохранение результата и получение видео с выбранного сервера. При проверке актуальный объединённый каталог содержал 1944 адреса. Через обычный интерфейс проверены старт с пустыми настройками, показ видео, обновление списка кнопкой, поиск по каталогу и ручное подключение. Сеть российского провайдера в этой проверке не воспроизводилась.

Изменения находятся в `ServerCatalog.kt`, `MainActivity.kt`, `PeerTubeApi.kt`, `ServerSettingsPage.kt`, ресурсах `values*/server_catalog.xml` и двух assets-файлах. Проверки добавлены в `ServerCatalogTest.kt`, `ServerCatalogSmoke.kt`, `ServerCatalogUiFixture.kt`, `AuthSmokeInstrumentation.kt`.
