# PeerIche 0.4.1

- Выбор субтитров перенесён с нативного диалога Media3 на Material Compose. Устранена зависимость этого действия от AppCompat-темы Activity; список обновляется при изменении дорожек, выбор проверяется перед применением. Отключение видимых субтитров сохраняется в настройках и не выключает активное TTS.
- Меню плеера уплотнено: иконка, название и текущее значение расположены в одной строке; доступны качество, субтитры, скорость, формат, озвучивание, мини-плеер и дополнительные параметры. На небольшом горизонтальном экране меню прокручивается.
- Кнопка «Картинка в картинке» возвращает предыдущую страницу PeerIche и открывает поверх неё перемещаемое видео с паузой, разворачиванием и закрытием. Воспроизведение и позиция сохраняются через существующий MediaSession.
- При сворачивании приложения во время воспроизведения по-прежнему используется системный PiP Android 8+, включая переход из внутреннего мини-плеера.
- Управление в полноэкранном горизонтальном режиме учитывает системные панели Android: верхние кнопки и нижняя шкала вынесены из области системных значков.
- Экран остаётся включённым при внутреннем плавающем воспроизведении; Android «Назад» в развёрнутом плеере сохраняет прежнее действие.
- Текст комментариев и ответов переводится вместе с названием и описанием: используются существующие переключатель перевода, целевой язык, модели и кеш. При недоступности перевода остаётся оригинал.
- Уменьшены вертикальные интервалы в окнах выбора, настройках озвучивания, комментариях и меню плеера; интерактивные строки сохраняют область нажатия не меньше 48 dp.

Изменены только файлы PeerIche. Другие приложения, зависимости, переводчик и TTS-движок не изменялись.

Проверки: `assembleDebug`, `assembleRelease`, `testDebugUnitTest` и `lintRelease` завершены успешно. 53 модульных теста, 0 ошибок lint (68 предупреждений). В отдельном эмуляторе API 37 проверены открытие субтитров из плеера и меню, выбор и повторное открытие немецкой дорожки, отключение субтитров, компактное меню, реальный перевод английских комментариев на русский, внутреннее плавающее окно, его перемещение и разворачивание, автоматический системный PiP из внутреннего окна и возврат в приложение, горизонтальное размещение управления. Падений AndroidRuntime не обнаружено. Повторная проверка на физическом устройстве пользователя необходима для подтверждения устранения его периодического вылета; исходный стек ошибки с устройства не предоставлялся.
