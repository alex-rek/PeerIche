# Трансляции с телефона — аудит

Исходная версия PeerIche 0.8.0, package/applicationId com.arcticfoxapps.peeriche, minSdk 23, compile/targetSdk 35, Kotlin 2.0.21, Media3 1.5.1. Авторизация, создание эфира и получение RTMP/RTMPS-параметров уже реализованы CreatorRepository и AccountSessionManager. Загрузка видео сохраняется.

MainActivity управляет нижним меню и планшетной панелью, верхнее меню отдельно открывает подписки. Добавляется отдельная страница создания: загрузка, трансляция, параметры канала. Нижняя кнопка меняется на «+» только при активном входе; без входа/при истёкшей сессии остаются «Подписки».

Для захвата, аппаратного H.264/AAC-кодирования и RTMP/RTMPS нужен отдельный транспорт. RootEncoder Apache-2.0 предоставляет StreamBase, Camera2Source, MicrophoneSource и смену источников. Выпуск 2.5.4 использует Kotlin 2.0.21 и совместим с текущим проектом; свежий 2.8.1 требует Kotlin 2.4 и не выбран. Existing Media3/Compose/SDK не обновляются. JitPack ограничивается группой RootEncoder.

Модель: foreground service camera|microphone, создание только из видимой Activity после runtime-разрешений. Без самозапуска, без записи камеры в файл и без сохранения stream key. Предпросмотр локальный, отдельная явная кнопка начала эфира. При выключенной камере источник заменяется заставкой, камера освобождается. Отключение микрофона прекращает захват/отправляет тишину. Поворот до запуска определяет размеры кодирования; во время эфира разрешение фиксируется, изображение поворачивается внутри него. При уходе с экрана до запуска камера освобождается; активный эфир управляется сервисом и уведомлением с остановкой.

Источники: https://github.com/pedroSG94/RootEncoder и wiki/StreamBase; https://developer.android.com/develop/background-work/services/fgs/service-types .
