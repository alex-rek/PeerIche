# PeerIche 0.7.0

- Подписки аккаунта на сервере и лента их видео с подгрузкой.
- Переключение между подписками аккаунта и подписками на устройстве без автоматического переноса данных.
- Собственные каналы и подписки аккаунта в разделе «Вы → Каналы».
- Оценки видео: нравится, не нравится и снятие оценки.
- Отправка комментариев и ответов; отображение статуса модерации и ошибок отправки.
- Безопасное разрешение удалённых видео на сервере аккаунта по UUID.

Публикация видео пока не поддерживается. Доступность действий зависит от правил выбранного сервера и федерации.

Подробности реализации и ограничения: [отчёт](https://github.com/alex-rek/PeerIche/blob/main/docs/ACCOUNT-FEATURES-REPORT.md).

APK подписан ключом предыдущих версий и подходит для обновления установленного приложения.

Проверки: 97 модульных тестов, Android smoke-тест и сборка успешны; lint — 0 ошибок, 75 предупреждений. Сертификат подписи совпадает с предыдущими релизами.
