# PeerIche 0.2.3

- На главной по умолчанию единая лента по дате публикации, от новых видео к старым, без группировки по каналам и с удалением повторов.
- Выбор сортировки: сначала новые, сначала старые, по просмотрам, по подборкам. Выбор сохраняется.
- Видео подписанных каналов сортируются по дате до ограничения количества, чтобы подборку не заполнял первый канал.
