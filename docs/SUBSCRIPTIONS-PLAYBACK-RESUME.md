# Подписки и продолжение просмотра

PeerTube отправляет создание подписки в очередь `activitypub-follow`, возвращая HTTP 204 до обновления списка подписок. Преждевременное обновление списка сбрасывало кнопку. Теперь принятые изменения сохраняются в состоянии приложения до подтверждения сервером, с повторными проверками в течение примерно двух минут. Повторное нажатие во время ожидания не создаёт второй запрос. Ошибки отправки не маскируются. Адрес канала используется независимо от сервера, через который получено видео.

Позиция видео сохраняется локально раз в две секунды, при паузе, перемотке, смене ролика и штатной остановке службы плеера. Следующее открытие продолжает просмотр автоматически. Завершённые ролики и прямые трансляции начинаются заново. История просмотра по-прежнему отмечается после пяти секунд; сохранённая позиция не возвращает просмотренные видео в главную ленту. Синхронизации позиции между устройствами нет. При аварийном завершении возможна потеря последних двух секунд.

Проверки включают задержку серверной подписки, повторное нажатие, сопоставление адресов каналов, правила восстановления позиции и Android-проверку службы плеера с локальным синтетическим аудиофайлом. Реальные аккаунты и публикации не используются.

Серверная реализация: https://github.com/Chocobozzz/PeerTube/blob/v8.3.2/server/core/controllers/api/users/my-subscriptions.ts
