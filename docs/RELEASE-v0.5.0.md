# PeerIche 0.5.0

- «Библиотека» в нижней навигации и планшетной панели заменена разделом «Вы» с иконкой профиля.
- На странице «Вы» размещены блок входа в аккаунт, «Каналы», «Избранное», «История» и «Настройки».
- Подготовлена точка входа для будущей авторизации: отображается текущий сервер и пояснение, что серверный вход пока не подключён. Пароли не запрашиваются, фиктивная сессия не создаётся.
- Каналы перенесены из переключателя подписок в «Вы». Сохранены подписанные каналы, просмотр их видео и каталог каналов сервера; каталог текущего сервера доступен и при пустом списке подписок.
- Избранное и история используют прежнюю локальную базу; есть отдельные страницы и возврат в меню «Вы».
- Шестерёнка общих настроек убрана из шапки. Выбор сервера в шапке сохранён, общие настройки доступны из «Вы».
- На странице подписок убран переключатель «Подписки / Каналы»; остаётся лента подписанных видео.
- Сохранены темы, адаптивная навигация, плеер, субтитры, перевод, мини-плеер и подготовленное в 0.4.2 скрытие системных панелей в полном экране.

Этот этап меняет интерфейс и навигацию. OAuth, серверные подписки и публикация видео будут подключаться отдельно. Миграция и удаление локальных данных не выполнялись.

Проверки: `assembleDebug`, `assembleRelease`, `testDebugUnitTest`, `lintRelease` — успешно. 53 теста, 0 ошибок lint (71 предупреждение). В отдельном эмуляторе API 37 проверены телефонная тёмная и планшетная светлая страницы «Вы», блок подготовки входа, настройки, пустые и заполненные избранное/история/каналы, возврат через Android «Назад», открытие каталога каналов сервера, отсутствие второго ряда кнопок в подписках, отсутствие шестерёнки в шапке и совместимость планшетного меню с мини-плеером. Тестовый ролик сохранён в избранное, попал в историю, подписка на его канал отобразилась в новом разделе. Падений AndroidRuntime не обнаружено. На физических устройствах отдельно не проверялось.
