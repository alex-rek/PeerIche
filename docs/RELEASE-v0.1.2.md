# PeerIche 0.1.2

- Background playback with the screen off, using a Media3 foreground service.
- Play/pause through Bluetooth headsets and Android media controls. Next/previous buttons seek ten seconds.
- Audio focus handling and pause when headphones disconnect.
- System media panel returns to the active video without restarting playback.
- PeerTube captions and supported embedded subtitle tracks via the player CC button.
- Closing the video explicitly stops playback.

Signed with the existing PeerIche release key. Install over 0.1.1 or use Settings → Check for updates. Device testing of screen-off and Bluetooth behavior remains pending; the available emulator was offline.
