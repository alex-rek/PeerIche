# PeerIche 0.9.0

- После входа нижняя кнопка «Подписки» заменяется кнопкой «+ / Создать». Без входа и при истёкшей сессии остаются «Подписки». Верхнее меню подписок сохранено.
- Страница создания с горизонтально прокручиваемым меню «Загрузка видео», «Трансляция», «Параметры канала». Shorts не добавлялись.
- Прямая трансляция с камеры телефона: H.264/AAC, RTMP и RTMPS, создание нового или выбор ожидающего эфира своего аккаунта.
- Локальный предпросмотр и режим тренировки без публикации. Передача начинается только отдельной кнопкой; по умолчанию новое видео личное.
- Накладные кнопки: передняя/задняя камера, микрофон, камера/заставка, ориентация и свет при поддержке камеры. Есть подписи кнопок, название и доступность, таймер и текущий битрейт.
- При выключении камеры вместо неё передаётся аватар или выбранная картинка; выключение микрофона заменяет захват тишиной.
- Фоновый сервис с уведомлением, возвратом на страницу трансляции и кнопкой завершения. Смена/выход из аккаунта останавливает передачу.
- Параметры своего канала: название, описание, выбор канала по умолчанию. Параметры эфира: качество, частота кадров, битрейт и заставка.
- Сохранены загрузки видео и создание эфиров для OBS. Поддерживаются телефон, планшет, светлая и тёмная темы.

Размер кодируемого кадра выбирается перед эфиром; во время передачи поворот меняет изображение внутри фиксированного кадра. После обрыва соединения повторное подключение запускается пользователем без автоматического создания второй публикации. Эффекты и ретушь не реализованы. Доступность эфиров, запись и ограничения определяются сервером.

APK подписан ключом предыдущих версий и подходит для обновления установленного приложения.

Проверки: 125 модульных тестов, Android smoke-тесты, синтетическая запись H.264/AAC и loopback RTMP, foreground-сервис с виртуальными камерами, смена источников и аккаунта — успешны. Сборка успешна, lint — 0 ошибок (89 предупреждений). Подпись совпадает с предыдущими версиями. Внешний эфир на сервер пользователя не создавался; совместимость с ним требует проверки на телефоне. Подробности: [отчёт](https://github.com/alex-rek/PeerIche/blob/main/docs/BROADCAST-REPORT.md).
