# PeerIche 0.8.0

- Раздел «Вы → Ваши видео» после авторизации: список собственных видео и эфиров, доступность, состояние обработки и подгрузка списка.
- Загрузка файла в собственный канал: название, описание, доступность, отметка контента для взрослых и необязательная обложка.
- Проверка квоты и формата по конфигурации сервера. Прогресс в приложении и фоновая передача с уведомлением, паузой, продолжением и отменой.
- Сохранение задания после закрытия процесса. Перед продолжением принятый объём сверяется с сервером; при ошибке нет автоматического создания новой публикации.
- Создание эфира для внешнего вещания (например, OBS): собственный канал, доступность, повторно используемый эфир и сохранение записи, если сервер разрешает.
- Получение адреса RTMP/RTMPS и ключа эфира в защищённом окне, копирование адреса, ключа и ссылки просмотра.

Съёмка камерой и передача эфира непосредственно с телефона запланированы следующим этапом. В этой версии PeerIche создаёт эфир, а поток отправляет внешняя программа.

Ограничения: одно задание загрузки одновременно; исходный файл должен оставаться доступным. Android и сервер ограничивают длительность фоновой передачи и срок жизни сессии загрузки. После остановки продолжение запускается пользователем. Удаление локального задания не удаляет опубликованное видео; закрытые ролики открываются на сайте сервера. Редактирование и удаление публикаций в приложении пока не добавлены.

APK подписан ключом предыдущих версий и подходит для обновления установленного приложения.

Проверки: 114 модульных тестов, Android smoke-тест и сборки успешны; lint — 0 ошибок, 82 предупреждения. Подпись совпадает с предыдущими релизами. Реальные публикации на сервер пользователя при проверке не создавались. Подробности и список файлов: [отчёт](https://github.com/alex-rek/PeerIche/blob/main/docs/CREATOR-REPORT.md).
