# PeerIche 0.1.0

First public preview by Arctic Fox Apps.

- PeerTube feeds, multi-source search and video playback.
- Local subscriptions, favorites and viewing history.
- Graphite launcher icon and compact navigation.
- Graphite, Light, blue Aurora and automatic Android themes.

Android 6.0+. The APK is signed with the dedicated PeerIche release key.

Known limitations: no account sign-in, background playback or Picture-in-Picture. Tablet/DeX and theme rendering still need device validation.

A release-signed APK cannot update a debug-signed installation. Back up any needed data before replacing a debug build.
