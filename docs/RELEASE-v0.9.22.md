# PeerIche 0.9.22

- Список «Далее» на странице видео теперь подбирается под открытое видео. Сначала идут новые видео того же канала, затем видео с такими же тегами и той же категории с сервера, где опубликовано видео. Если похожих мало, список дополняется видео с Главной. Трансляции, скрытые каналы и скрытые видео в список не попадают, уже просмотренные видео перемещаются в конец.
- Главная больше не показывает трансляции: для них есть отдельный раздел «В эфире».
- В «Настройки → Сеть» тип прокси выбирается кнопками «Без прокси», «HTTP» и «SOCKS5» прямо на странице. Поля адреса, порта и входа показываются только для HTTP и SOCKS5.
- Исправлено: поле «Адрес прокси» обрезалось при открытой клавиатуре.

APK подписан прежним релизным ключом и устанавливается поверх предыдущих версий. База данных не менялась.

Проверки: 206 модульных тестов и Android Lint без ошибок. На реальном телефоне вручную проверены экран «Сеть» с клавиатурой, Главная без трансляций и список «Далее».
