# Мобильная ориентация трансляции

В мобильном разделе создания Activity зафиксирована в портретной ориентации. Предыдущая настройка восстанавливается при выходе из раздела. Планшетная навигация не изменена.

Нижняя панель имеет высоту 72 dp, значки 22 dp и центрированные подписи с одинаковым местом под две строки. Дублирующий нижний системный отступ NavigationBar убран: безопасный отступ предоставляет внешний Scaffold.

Кнопка ориентации использует существующее переключение размера закодированного кадра. В мобильном интерфейсе поворачивается только слой управления с надписями и информационным блоком. TextureView предпросмотра находится за пределами поворачиваемого Compose-блока: камера не получает дополнительного поворота от интерфейса. Нижняя панель не поворачивается. Режим предпросмотра остаётся Adjust.

Дополнительный фильтр вписывания камеры, введённый в 0.9.9, удалён: вместе со штатным вписыванием предпросмотра он уменьшал изображение дважды. Цепочка фильтров содержит только необязательный логотип. Отношением сторон предпросмотра управляет штатный режим Adjust видеодвижка. Дополнительные растягивание, обрезка и поворот камеры в Compose не применяются.

Существующее ограничение смены закодированного формата во время активного RTMP-эфира сохранено: формат выбирается до запуска. Физический поворот телефона не меняет его.

Проверки: сборка debug/androidTest, 149 модульных тестов, Lint без ошибок. Отдельный Android-тест использует Camera2Source с виртуальной камерой virtualscene эмулятора: локально записывает оба формата, декодирует кадры и проверяет отсутствие двойного уменьшения. Прежние тесты, основанные на предположении о растянутой входной текстуре камеры, удалены вместе с ошибочным фильтром. Ранее на эмуляторе 5556 с телефонным размером проверены сохранение положения нижнего меню и отсутствие смены ориентации Activity при изменении системного user-rotation. Реальные аккаунты и публикации не используются.
