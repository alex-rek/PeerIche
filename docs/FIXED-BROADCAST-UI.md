# Мобильная ориентация трансляции

В мобильном разделе создания Activity зафиксирована в портретной ориентации. Предыдущая настройка восстанавливается при выходе из раздела. Планшетная навигация не изменена.

Нижняя панель имеет высоту 72 dp, значки 22 dp и центрированные подписи с одинаковым местом под две строки. Дублирующий нижний системный отступ NavigationBar убран: безопасный отступ предоставляет внешний Scaffold.

Кнопка ориентации использует существующее переключение размера закодированного кадра. В мобильном интерфейсе меняются местами логические ширина и высота области трансляции, после чего она поворачивается на 90 градусов внутри неизменного экрана. Нижняя панель не поворачивается. Предпросмотр использует TextureView, чтобы видеоповерхность участвовала в преобразовании вместе с элементами Compose. Внутри области поворачиваются изображение, логотип, информационный блок и кнопка запуска/остановки. Режим масштабирования движка остаётся Adjust: изображение не растягивается и не обрезается, полосы допустимы.

Существующее ограничение смены закодированного формата во время активного RTMP-эфира сохранено: формат выбирается до запуска. Физический поворот телефона не меняет его.

Проверки: сборка debug/androidTest, 149 модульных тестов, Lint без ошибок. На эмуляторе 5556 с телефонным размером проверены оба состояния кнопки, сохранение положения нижнего меню и отсутствие смены ориентации Activity при изменении системного user-rotation. Тест использовал фиктивный аккаунт и заглушку без отправки эфира.
