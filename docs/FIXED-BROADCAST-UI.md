# Мобильная ориентация трансляции

В мобильном разделе создания Activity зафиксирована в портретной ориентации. Предыдущая настройка восстанавливается при выходе из раздела. Планшетная навигация не изменена.

Нижняя панель имеет высоту 72 dp, значки 22 dp и центрированные подписи с одинаковым местом под две строки. Дублирующий нижний системный отступ NavigationBar убран: безопасный отступ предоставляет внешний Scaffold.

Кнопка ориентации использует существующее переключение размера закодированного кадра. Размер TextureView на телефоне вычисляется по отношению короткой стороны к длинной, поэтому перестановка размеров записи 1080×1920 / 1920×1080 не меняет область предпросмотра. Поворот камеры для кодирования и компенсирующий поворот предпросмотра задаются раздельно. Предпросмотр камеры отображается в заранее вписанной области с тем же отношением сторон; режим NONE не добавляет повторного вписывания после компенсации. Для планшета сохранён Adjust.

Перемещаются кнопки закрытия, «Поделиться» и запуска/остановки. Логотип поворачивается вместе с выходным кадром при компенсации предпросмотра. Информация, боковая и нижняя панели остаются на месте. При переходе в параметры во время эфира выбранный поворот кодирования сохраняется.

Дополнительный фильтр вписывания камеры, введённый в 0.9.9, удалён. Цепочка фильтров содержит только необязательный логотип. Дополнительные растягивание, обрезка и поворот камеры в Compose не применяются.

Существующее ограничение смены закодированного формата во время активного RTMP-эфира сохранено: формат выбирается до запуска. Физический поворот телефона не меняет его.

Проверки: сборка debug/androidTest, 151 модульный тест, Lint без ошибок. Проверяются постоянное отношение сторон предпросмотра и взаимная компенсация поворотов. Отдельный Android-тест использует Camera2Source с виртуальной камерой virtualscene эмулятора: локально записывает оба формата с теми же преобразованиями, декодирует кадры и проверяет отсутствие двойного уменьшения. Прежние тесты, основанные на предположении о растянутой входной текстуре камеры, удалены вместе с ошибочным фильтром. Реальные аккаунты и публикации не используются.
