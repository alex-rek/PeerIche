# PeerIche 0.2.0

- Шестерёнка в верхней панели и полноэкранные настройки с шестью разделами.
- Выбор темы, языка интерфейса и страны.
- Настройка источников поиска, приоритетов, режима выполнения, сортировки и фильтров.
- Проверка и подключение серверов, поиск по каталогу, сортировка по доступности и количеству видео.
- Локальный перевод названий, описаний и поддерживаемых субтитров; управление языковыми моделями.
- Параметры воспроизведения по умолчанию и оформление субтитров.
- Экран сведений о приложении с ручной проверкой обновления.

Первоначальная загрузка языковых моделей требует подключения к сети. Перевод субтитров доступен для видео с текстовыми субтитрами.

Проверки: 16 модульных тестов; Android lint без ошибок. В эмуляторе проверены навигация настроек, сохранение параметров, язык интерфейса, подключение сервера, загрузка/удаление модели, оформление субтитров и проверка обновлений.
