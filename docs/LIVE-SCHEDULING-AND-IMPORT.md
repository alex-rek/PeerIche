# Планирование эфиров и импорт по ссылке

В параметрах новой трансляции и в форме создания эфира для OBS доступны дата и время начала. При сохранении расписания создаётся серверный анонс без подключения RTMP. В «Ваших видео» отображается дата; доступны изменение/снятие расписания, ссылка «Поделиться» и переход к запуску выбранного эфира с телефона. Установка времени не запускает камеру автоматически.

Поддержка определяется по `serverVersion` из `/api/v1/config`: требуется PeerTube >= 7.3. На более старых/неизвестных версиях планирование недоступно, обычные эфиры сохраняются. Время выбирается в часовом поясе устройства и передаётся в UTC. Прошедшее время отклоняется. Создание использует `schedules[0][startAt]` в multipart, изменение — `schedules` в JSON PUT, снятие расписания — пустой массив. Список собственных видео уже запрашивается с `includeScheduledLive=true`; дата читается из `liveSchedules`, а параметры конкретного эфира — из `schedules`.

При импорте по URL название и описание необязательны. Пустые значения не отправляются, поэтому существующий загрузчик PeerTube получает данные из источника. Введённый текст имеет приоритет. Предварительного разбора сайта на телефоне и отдельного загрузчика нет: данные появятся в карточке на сервере после принятия импорта. Поддержка источника и доступность видео зависят от серверного загрузчика.

Для POST импорта увеличено ожидание с 30 до 120 секунд: сервер получает информацию об источнике до ответа. При неопределённом результате выполняется только чтение списка импортов. Новый недавний импорт с той же ссылкой и новым идентификатором подтверждает принятие; старое задание успехом не считается. Если исходный список прочитать не удалось, подтверждение по сравнению не выполняется. Повторного POST автоматически нет. При сохранении неопределённости показывается прежняя рекомендация проверить «Ваши видео» перед повтором. Ошибки 400 источника и отключённый импорт имеют отдельные сообщения. Точный источник ошибки из пользовательского скриншота требует исходной ссылки.

Проверки: debug/APK androidTest, 158 модульных тестов, Lint без ошибок. Новые тесты покрывают UTC/форматы API, версии сервера, прошедшее время, создание/снятие расписания, вложенные multipart-поля, необязательные/заданные метаданные и сверку импорта после обрыва без дублирования публикации. UI проверяется на эмуляторе с фиктивным аккаунтом, без реальных серверных публикаций. Открытая конфигурация tube.articfox.cc на момент проверки: PeerTube 8.3.2, live и HTTP import включены.

Основные изменённые файлы: `LiveScheduling.kt`, `AccountOperations.kt`, `CreatorRepository.kt`, `PeerTubeAuth.kt`, `VideoUrlImport.kt`, `CreatePage.kt`, `CreatorPage.kt`, `MainActivity.kt`; строки добавлены для всех 11 языков интерфейса. Проверки: `LiveSchedulingTest.kt`, `AccountOperationsTest.kt`, `CreatorProtocolTest.kt`, `CreatorUiFixture.kt`.
