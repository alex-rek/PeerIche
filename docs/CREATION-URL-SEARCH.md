# Настройки озвучивания, создание и поиск

- «Язык и переводы» содержит пункт «Субтитры → Озвучивание» сразу после переключателя перевода субтитров. Он использует существующий экран и общие настройки озвучивания. Возврат ведёт в тот раздел, из которого открыт экран.
- На телефоне режимы создания представлены стандартными NavigationBarItem с иконками и подписями. На планшете режим выбран через дополнительную группу в левой панели, отделённую разделителем. Состояние выбранного режима общее для панели и содержимого.
- «Загрузка из URL» использует серверный импорт PeerTube: POST /api/v1/videos/imports с multipart-полями targetUrl и существующими метаданными публикации. Разрешение берётся из import.videos.http.enabled. Выбираются название, описание, канал, доступность и отметка чувствительного контента. Скачивание и обработка выполняются сервером; результат доступен в «Ваших видео». Функция не скачивает исходный файл на телефон и не создаёт локальное задание передачи. Импорт не повторяется автоматически при сетевой ошибке; при неподтверждённом результате предлагается проверить список видео перед повтором.
- На странице поиска есть сохранённый выбор сортировки: соответствие запросу, сначала новые, просмотры. Он использует тот же параметр, что и настройки поиска. При смене сортировки поиск перезапускается, позиция списка сбрасывается. Новые страницы объединяются с уже загруженными с сохранением порядка по дате или просмотрам.

Ограничения: импорт должен быть разрешён администратором сервера; доступность конкретных сайтов и форматов определяется сервером, его загрузчиками и квотой аккаунта. Между устройствами режимы поиска и настройки не синхронизируются.

Проверки: 147 модульных тестов; сборка debug и androidTest; Lint без ошибок; 567 строк во всех 11 языковых каталогах. На эмуляторе 5556 проверены телефонная нижняя панель, планшетная боковая группа, форма URL, три режима сортировки и возврат из озвучивания в «Язык и переводы». UI использует фиктивный аккаунт; реальных импортов и публикаций не выполнялось.
