# PeerIche 0.6.0

- В разделе «Вы» подключён вход в аккаунт сервера PeerTube по имени пользователя и паролю, включая двухфакторный код.
- Несколько сохранённых аккаунтов, переключение активного аккаунта и его сервера. В профиле отображаются имя, адрес аккаунта и аватар.
- Проверка профиля после входа, автоматическое обновление истекающих токенов и повторный вход после отзыва сессии.
- Токены зашифрованы AES-256-GCM с ключом Android Keystore и исключены из резервных копий. Пароль не сохраняется. Окно входа защищено от снимков экрана.
- Выход удаляет локальный вход и пытается завершить серверную сессию. Если сервер недоступен, приложение сообщает, что серверную сессию нужно отозвать на его сайте.
- Понятные сообщения об ошибках пароля/OTP, блокировке аккаунта, неподтверждённой почте, одобрении регистрации, ограничении попыток и ошибках соединения.
- Локальные подписки, избранное и история сохранены отдельно. Их серверная синхронизация, публикация контента и вход через внешние SSO-сервисы будут подключаться отдельно.

Подробности архитектуры и предварительного аудита: [AUTH-AUDIT.md](https://github.com/alex-rek/PeerIche/blob/v0.6.0/docs/AUTH-AUDIT.md).

Проверки: 79 модульных тестов, 0 ошибок lint (72 предупреждения); сборки debug/release и отдельного Android-теста успешны. На эмуляторе API 37 прошла проверка Android Keystore, восстановления зашифрованной сессии, вращения refresh-токена, отклонения повреждённого файла, восстановления AtomicFile и выхода. Проверены формы телефона/планшета, OTP, очистка пароля и защита окна входа. Сценарии OAuth проверены на контролируемых ответах; реальный аккаунт не использовался. SSO и серверная синхронизация пока не поддерживаются.
