# PeerIche 0.4.0

- Страница просмотра по образцу мобильного SingeeIche: название и статистика под видео, сворачиваемое описание, строка канала с аватаром и подпиской, компактные рекомендации «Далее».
- Публичные комментарии PeerTube и ответы открываются в нижней всплывающей панели; есть повторная загрузка и постраничная подгрузка.
- Прозрачные элементы управления: «Назад» слева вверху плеера; справа — PiP, озвучивание, субтитры и настройки. Кнопка полного экрана остаётся справа внизу.
- Меню плеера: качество, субтитры, скорость, формат кадра, параметры озвучивания и дополнительные настройки.
- «Поделиться» открывает системное меню Android с названием и публичной ссылкой на видео.
- «Картинка в картинке»: по кнопке и при сворачивании воспроизводимого видео. В маленьком окне остаются видео и субтитры; Android «Назад» сохраняет навигацию приложения.
- Сохранены планшетная компоновка, темы, действующие субтитры, перевод, TTS и управление через MediaSession.
- Включены исправления загрузки разделов «На сервере» и «В эфире» из 0.3.1.

PiP требует Android 8+ и разрешения системы для приложения. Автоматический переход выполняется для воспроизводимого видео; пауза не запускает PiP при сворачивании. Комментарии доступны для чтения, если сервер и автор разрешают их; вход в аккаунт и публикация комментариев не добавлялись. Подписки остаются локальными.

Другие проекты использованы только как справочный материал и не изменялись. Зависимости, название, package name и applicationId сохранены.

Проверки: `assembleRelease`, `assembleDebug`, `testDebugUnitTest` — успешно, 49 тестов без ошибок; `lintRelease` — 0 ошибок, 67 предупреждений. В отдельном эмуляторе API 37 проверены телефонная тёмная и планшетная светлая компоновки, комментарии и ответы, системное меню отправки ссылки, ручной и автоматический PiP, продолжение воспроизведения в PiP, возврат в приложение и Android «Назад» к карточкам. Падений AndroidRuntime не обнаружено. Проверка на физических устройствах и версиях Android 8–11 отдельно не проводилась.
