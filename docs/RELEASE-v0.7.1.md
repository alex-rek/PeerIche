# PeerIche 0.7.1

- Лайки и дизлайки отображаются только при активной авторизации на сервере.
- Оценки, избранное, «Поделиться», озвучивание и видео канала собраны в одну горизонтально прокручиваемую строку.
- Без авторизации скрыты отправка комментариев и предложение входа из окна комментариев. Публичные комментарии и ответы остаются доступны для чтения.
- При истёкшей сессии серверная подписка на странице видео скрывается до повторного входа. Локальные подписки и избранное сохраняются и работают без входа.

Войти в аккаунт можно на странице «Вы». Изменение состояния входа автоматически обновляет видимость действий.

Проверки: assembleDebug, assembleDebugAndroidTest, assembleRelease, testDebugUnitTest и lintRelease успешны. 97 тестов, 0 ошибок lint (75 предупреждений). Android smoke-тест с изолированными данными успешен. Проверено чтение публичных комментариев без элементов отправки и отсутствие отдельной строки оценок без входа. Настоящие оценки и комментарии при проверке не отправлялись.
