# PeerIche 0.9.20

- Добавлен раздел «Настройки → Сеть» по образцу RussTube: без прокси, HTTP и SOCKS5, адрес, порт, необязательные логин и пароль, сохранение, проверка HTTPS-соединения и сброс.
- Прокси подключён к API и авторизации PeerTube, поиску и каталогу серверов, изображениям, плееру Media3, субтитрам, скачиванию и загрузке видео, а также проверке обновлений. Новые запросы используют сохранённые параметры без перезапуска приложения.
- Конфигурация хранится отдельно в зашифрованном хранилище Android Keystore. Реквизиты пользователя не включены в APK. Ошибка подключения к прокси не приводит к прямому обходу; проверка сертификатов TLS сохранена.
- Параметры переведены на все 11 языков интерфейса. RTMP-эфиры с телефона и управляемая SDK загрузка моделей перевода используют отдельные соединения и этим прокси не охватываются. После изменения маршрута воспроизводимое видео следует открыть заново.

APK подписан прежним релизным ключом и устанавливается поверх предыдущих версий.

Проверки: подписанная релизная сборка, 182 модульных теста и Android Lint без ошибок. На отдельном Android-эмуляторе проверены HTTP/SOCKS5 с авторизацией и без неё, HTTPS API и изображения, чтение диапазонов видео, реальное воспроизведение через авторизованный CONNECT, зашифрованное хранение, отказ при неверном пароле, сохранение и сброс через интерфейс, телефонная и планшетная компоновки. Предоставленный пользователем внешний прокси успешно проверен на обоих портах через публичный HTTPS API без публикации его реквизитов.
