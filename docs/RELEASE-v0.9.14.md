# PeerIche 0.9.14

- Добавлено планирование трансляций: дата и время в параметрах нового эфира, изменение и снятие расписания, отображение даты в «Ваших видео», ссылка «Поделиться» и переход к запуску выбранного эфира с телефона. Требуется PeerTube 7.3 или новее; время анонса не запускает трансляцию автоматически.
- При импорте по ссылке название и описание можно оставить пустыми — сервер получит их из источника. Свой текст можно указать вручную.
- Ожидание ответа импорта увеличено до 120 секунд. При обрыве ответа приложение проверяет, появилось ли новое задание на сервере, без повторной отправки запроса публикации. Добавлены отдельные сообщения об ошибках источника и отключённом импорте.
- Новые элементы переведены на все 11 языков интерфейса.

APK подписан прежним ключом и устанавливается поверх предыдущих версий.

Проверки: подписанная релизная сборка, 158 модульных тестов, Android Lint без ошибок. На эмуляторе с фиктивным аккаунтом проверены отображение и изменение расписания, выбор эфира для запуска и импорт с пустыми полями метаданных. Реальных публикаций на сервере в тестах нет.

Доступность конкретного источника импорта зависит от загрузчика на сервере. Для проверки причины ошибки из пользовательского скриншота требуется исходная ссылка.
