# PeerIche 0.9.2

- Исправлен отказ загрузки видео и создания эфира с пустым описанием. Описание можно оставить пустым; заполненное должно содержать от 3 до 10 000 символов.
- Исправлена остановка загрузки на 0 Б: поддержан ответ пустой сессии node-uploadx, используемой PeerTube. После обновления можно нажать «Продолжить» у сохранённого задания.
- Вместо ошибочного сообщения про API входа показываются ошибки публикации; добавлены сообщения об ограничениях числа эфиров.
- В разделе «Ваши видео» добавлены миниатюры и просмотр в плеере приложения, включая личные ролики и активные эфиры. Запись завершённого эфира доступна после обработки и публикации сервером.
- Доступ к личным видео использует временный токен файла. Выход и смена аккаунта останавливают личное воспроизведение. Кнопка «На сайте» сохранена.

APK подписан прежним ключом и устанавливается поверх предыдущих версий. Просмотр личных файлов на отдельном CDN пока не поддерживается. Проверки выполнялись без публикации видео на аккаунте пользователя; личный просмотр на его сервере требует проверки после установки.

Проверки: релизная сборка успешна, 134 модульных теста прошли. Lint: 0 ошибок, 90 предупреждений. Подпись APK совпадает с предыдущими версиями.
