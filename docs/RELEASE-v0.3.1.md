# PeerIche 0.3.1

- «На сервере»: понятное сообщение для адресов без PeerTube API и кнопка перехода к выбору сервера. Обычная HTML-страница или посторонний JSON больше не принимаются при подключении.
- «В эфире»: популярные трансляции проверяются на исходных серверах; пустые страницы ожидающих/завершённых эфиров пропускаются автоматически с сохранением позиции следующей страницы.
- При недоступности каталога используются резервные федеративные источники. Ошибочно выбранный сторонний сайт не блокирует общий поиск эфиров.
- Повторные таймауты одного недоступного сервера ограничены. Ошибки подключения отделены от отсутствия активных эфиров.

PeerIche подключается к серверам PeerTube. Odysee использует другой API и не является совместимым сервером PeerTube.

Проверки: 44 модульных теста пройдены; Android lint без ошибок. В эмуляторе воспроизведён сохранённый адрес odysee.com: показано сообщение о несовместимости, кнопка открывает настройки серверов; после подключения peertube.tv карточки загружаются. Глобальные эфиры загружаются и при выбранном Odysee.
