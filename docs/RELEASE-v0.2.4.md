# PeerIche 0.2.4

- Исправлены относительные адреса миниатюр федеративных видео: используются сервер подборки, исходный сервер, запасное изображение и уточнение адреса по данным ролика.
- Видео попадает в историю после пяти секунд фактического воспроизведения. Загрузка и паузы не засчитываются; перемотка не ускоряет отметку просмотра. Учёт работает и при фоновом воспроизведении.
- Просмотренные видео скрываются со всей главной, включая режим «По подборкам».
- По окончании видео приложение возвращается к карточкам.
- Полноэкранная кнопка не меняет ориентацию телефона принудительно.
- В плеере добавлен выбор формата: исходный, 16:9, 4:3, 1:1, 21:9; выбор доступен также в настройках плеера.
