# Скрытые каналы

Последний пункт горизонтальной строки действий под видео — «Скрыть канал». Для уже скрытого канала тот же пункт меняет название на «Показать канал» и выполняет обратное действие. Строка канала и кнопка подписки не изменены.

Скрытие локальное, общее для устройства, работает независимо от авторизации. Фильтруются все блоки главной и все варианты её сортировки. Поиск, «На сервере», эфиры, отдельная страница подписок, история и избранное не фильтруются. Прямое открытие видео остаётся доступным.

Используется существующая Room-таблица библиотеки, отдельный вид записи `hidden_channel`. Миграция и изменение схемы не нужны. Идентификатор совпадает с используемым для подписок: имя канала и его исходный сервер, а не сервер, через который найдено видео. Поэтому скрываются федеративные копии того же канала, но не одноимённые каналы на других серверах. Если стабильного имени канала нет, действие недоступно; совпадения только по отображаемому названию не используются.

В «Настройки → Скрытые каналы» можно вернуть любой канал. Запросы на подписку, отписку или серверную блокировку не выполняются. Изменения состояния записываются асинхронно через Room. Подписи добавлены для всех 11 языков интерфейса.

Проверки: debug и androidTest APK, 161 модульный тест, Lint без ошибок. Новые тесты проверяют исходный сервер, федеративные копии, одноимённые каналы и отсутствие надёжного идентификатора. Проверка Room на эмуляторе закрывает и повторно открывает отдельную тестовую базу, подтверждает сохранение скрытия и восстановление без удаления записи подписки. UI проверяется на отдельном локальном канале без публикаций или изменений аккаунта; тестовая запись удаляется после проверки.

Изменённые файлы: `HiddenChannels.kt`, `MainActivity.kt`, `WatchPage.kt`, `SettingsScreen.kt`, `values*/hidden_channels.xml`; проверки — `HiddenChannelsTest.kt`, `HiddenChannelsSmoke.kt`, `HiddenChannelsUiFixture.kt`, `AuthSmokeInstrumentation.kt`.
